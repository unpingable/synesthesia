# v0.2.0 qualification

Qualification was performed on 2026-07-26 on x86_64 Linux
6.8.0-136-generic with glibc 2.39. Release binaries were built with the
declared Rust 1.85.1 toolchain.

## Process weather

The unprivileged process source was sampled at its default 250 ms interval in
100x30 ASCII snapshots. The status counters distinguished the controlled
states:

| State | Semantic activity observed |
| --- | --- |
| Quiet | 4 events/s; no CPU or I/O deltas |
| One CPU worker | 14 events/s; 6 CPU events/s |
| All CPU workers | 42 events/s; 24 CPU events/s |
| 128 MiB bounded write | 20 events/s; 8 I/O events/s |
| 100 short-lived tasks | 207 events/s; 199 observed exits/s |
| Settle | 4 events/s; no CPU or I/O deltas |

Each state produced a different deterministic snapshot hash for its observed
sample. The temporary I/O file and workload processes were removed before the
qualification command returned. These are qualitative source checks, not
benchmarks or utilization measurements.

## Renderer and regressions

The complete formatter, strict Clippy, test, eBPF feature check, release build,
metadata, and offline package-inspection gates passed. The suite contained 131
tests: 129 passed and the two privileged live-tracepoint attachment tests were
ignored by design.

Demo, line input, process mode, and scheduler/TCP flight-recorder fixture
snapshots contained printable ASCII and newlines only, with no escape or cursor
control bytes. A repeated particle-disabled demo snapshot was byte-identical.
The ANSI demo snapshot retained a materially different Unicode rendering.

## Binary archive

`scripts/build-release.sh` was run from one clean commit with two independent
Cargo target directories. The resulting tarballs compared byte-for-byte
identical. Each contained only:

- `synesthesia`
- `synesthesia-scheduler-collector`
- `synesthesia-tcp-collector`
- `README.md`
- `RELEASE_NOTES.md`
- `LICENSE`
- `NOTICE`

Archive paths, order, timestamps, ownership, and modes were normalized. The
three binaries contained no local home-directory path, had no setuid bits or
file capabilities, and dynamically linked only the expected glibc-family
runtime libraries. From a clean extraction, demo, unprivileged process mode,
and fixture replay succeeded. Scheduler and TCP modes refused unprivileged
attachment with the explicit insufficient-eBPF-permissions classification.

The final published checksum is generated again from the tagged commit and is
verified as a release asset rather than hard-coded into this source note.
